# Third party notices of the window

The window, `certdoctor-gui`, is Copyright (C) 2026 DonislawDev and is licensed
under the GNU General Public License, version 3. The full text is in
[LICENSE](LICENSE).

The window also contains work that other people made: the Go runtime and
standard library, the Fyne graphics toolkit and the twenty five modules it
brings with it, the GLFW library in C that opens the window and reads its input,
and the Inter typeface its text is set in. Their licences ask that their notices
travel with every copy, a binary one included, so this file is part of every
release archive that carries the window. Each of these licences is compatible
with GPL-3.0.

The command line, `certdoctor`, links none of this but `golang.org/x/text`, and
its notices are in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). That is why
the window has a file of its own - `certdoctor --license` prints the notices of
the code the command line carries, and no more.

The window is built for Windows on amd64, Linux on amd64 and macOS on arm64.
Twenty five of the modules below are in all three builds, and
`github.com/rymdport/portal` is in the Linux build alone. GLFW compiles
different C files on each platform, and a notice below that belongs to one
platform says so.

What this file lists is checked rather than asserted. A guard in the source
asks the build, for each of the three, which packages it links, and follows
every `#include` of their C code to the files it reaches. It fails when a module
is missing here, when a version here is not the one linked, when a licence file
beside linked code, beside a C file it includes or beside a font it embeds is
not reproduced in full under its own heading, or when a line of linked source
that states a copyright or names a GNU licence is not quoted under it.

Each section opens with the version every build links and an SPDX licence
expression that names every text quoted in that section, in the order they
appear. Texts that match no entry on the SPDX License List are named
`LicenseRef-` here.
